# Outbound volume deliverability plan

## Plan
- Secondary look-alike domains with SPF, DKIM, and DMARC.
- 2 to 3 week warmup.
- About 25 sends per inbox per day. Start with 2 domains x 2 inboxes (about 100 a day).
- Weekday sending by default.
- An opt-out line in every email.
- US CAN-SPAM requires a physical mailing address (a PO box or virtual mailbox is OK). Treat this as US-oriented guidance and follow the rules that apply where the user sends from.
