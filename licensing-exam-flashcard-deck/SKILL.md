# Licensing exam flashcard deck

## Steps
1. The study guide is the core. List every item, plus topics it says are not on the exam.
2. Research beyond it: the official exam content outline and high-yield topics.
3. Fact-check every item against primary sources (the official exam outline, current license law and regulator rules for the user's jurisdiction, and current official forms). Correct anything wrong or outdated.
4. Build flashcard import files: one card per line, term TAB definition, no header, one fact per card, fronts phrased as questions. One deck per exam portion, plus a small deck for formulas or calculations if the exam can include them, even if the guide downplays that.
5. Write a corrections file listing each guide error with its source URL.
6. Deliver the decks with import steps. Lead with the biggest corrections. Offer quiz drills on the hardest examples.

## Rules
- Go beyond the notes. Be accurate. Keep cards memorization-friendly.
