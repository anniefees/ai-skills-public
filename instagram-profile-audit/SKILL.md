# Instagram profile audit

## Steps
1. Pull the profile, recent posts, reels, highlights, and reel transcripts.
2. Make a contact sheet of the grid and recent covers.
3. Audit the bio and name field, the grid (content mix, are top performers hidden?), hooks (numbers, curiosity, payoff on screen at second 0), CTAs, and the number of content lanes.
4. Deliver a short critique, the top 5 fixes, and 2 to 3 plain bio options tied to the niche.

## Rules
- Read only. Never invent metrics. Never change the profile.
