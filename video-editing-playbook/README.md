# Video editing playbook

A draft skill for editing spoken videos, tutorials, vlogs, text-led footage, music-led montages, performance clips, and series videos.

The aim is trust and clarity: a viewer can follow the point, and the footage supports what the piece shows. Views and virality are outside this skill.

**Status: draft. Real export validation is pending.** This is not a fixed or approved production workflow. This page does not report an export test result.

## How to use it

1. Add [SKILL.md](SKILL.md) to your own assistant.
2. Keep the native kit you have already approved (title preset, captions, filter, layout, cover template, and authorized audio) in a style specification you control. The skill binds to that kit. It does not include one.
3. Bring the brief, the authorized source version, and any take default you have already approved.
4. Use the editor you already have, and a way to watch the export and listen on headphones. No vendor API or paid account is required.
5. Follow the skill in order: brief and intent, hook / story / payoff, speech assembly, external brand binding, captions and picture and sound, full export review, then revision and retest.
6. Fill the edit plan, output manifest, and review notes in [SKILL.md](SKILL.md). Those templates stay in that file.
7. Leave publishing and scheduling for a separate approval. Review the rendered video and audio. File metadata and stills do not replace that review.
